# FormCraft

FormCraft is a polished no-code form builder built for a frontend and UI/UX portfolio. It presents a real SaaS-style product surface where users can visually compose form schemas, customize fields, preview the rendered experience, and export form or submission data without writing code.

## Features

- Drag-and-drop form builder with `dnd-kit`
- Typed JSON form schema with reusable field models
- Field settings for labels, placeholders, helper text, required state, options, validation, and multi-step grouping
- Schema-driven form preview using React Hook Form and Zod validation
- Desktop and mobile preview modes
- Local mock submission capture with searchable table, detail drawer, and CSV export
- Templates for contact, job application, event registration, feedback survey, and lead generation flows
- Theme settings for accent color, rounded/square style, light/dark preview, title, and description
- localStorage persistence through Zustand
- Responsive SaaS dashboard UI with accessible labels and focus states

## Stack

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Build for production:

```bash
npm run build
```
